# Earth map data

`world-110m.json` is the pinned `countries-110m.json` asset from world-atlas 2.0.2:
https://cdn.jsdelivr.net/npm/world-atlas@2.0.2/countries-110m.json

It redistributes Natural Earth 1:110m country boundaries (Natural Earth 4.1.0).
Natural Earth data is public domain: https://www.naturalearthdata.com/about/terms-of-use/
The world-atlas redistribution license is retained in LICENSE-world-atlas.

The map is illustrative, not a statement about political boundaries.
City pins are approximate city centres selected by the portfolio owner:
Shanghai (31.2304, 121.4737), Bangkok (13.7563, 100.5018),
Helsinki (60.1699, 24.9384). Only Helsinki is described as the current base.
No other residence, travel history, dates or affiliations are inferred.
